# Diseño y desarrollo de juego serio para mejorar la capacidad de planificación en niños y adolescentes con TDAH
Este repositorio contiene los archivos de los datos sobre el Trabajo de Fin de Grado del curso 2025-2026 del grado en Desarrollo de Videojuegos realizado por Nahia Iglesias Calvo y dirigido por Alejandro Romero Hernández.
El proyecto del TFG se encuentra en el siguiente repositorio: https://github.com/UCMActLab/ColombianTDAH.git

## Archivos
En este TFG se realizaron pruebas a 49 usuarios y se han guardado los datos obtenidos del juego en archivos json que se encuentran en la carpeta "MisionColombiaJsons".
La carpeta "CalculosDatos" contiene los datos en crudo, las correlaciones y las medias y desviaciones típicas calculadas de los archivos json mencionados anteriormente. Estos cálculos de media se han creado con el archivo "jsonToCsvMetricas.py" que crea también todos los archivos de métricas de esta carpeta.
Por último, la carpeta "MemoriaTFG" contiene la memoria del TFG y la presentación de la defensa.
